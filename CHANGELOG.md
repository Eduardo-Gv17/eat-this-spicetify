# Changelog

## v0.1.0 — 2026-10-26

First standalone Spicetify release.

- Browse and search saved playlists, including folders.
- Load playlists by card, link, or context-menu shortcut.
- Play Snake with playlist cover artwork and Spotify playback.
- Select an estimated intense section, fixed offsets, or the beginning of each song.
- Choose three speeds and pause or restart a game.
- Minimal connected snake, directional eyes, and outlined food.
- Windows source installer, installable ZIP, tests, and contribution guide.

The in-app interface is currently Spanish. Windows gameplay has been tested by the project owner; exact client versions and other platforms still need a compatibility matrix.
